# Multiplication Table Generator (Java)

## Overview

The **Multiplication Table Generator** is a simple Java console application that prompts the user to enter a number and then displays its multiplication table from **1 to 10**. This project demonstrates the use of user input, loops, arithmetic operations, and formatted console output in Java.

## Features

* Accepts a number from the user.
* Generates the multiplication table from **1 to 10**.
* Displays results in a clean and readable format.
* Beginner-friendly Java project.

## Technologies Used

* Java
* Eclipse IDE (or any Java IDE)
* Java Scanner Class
* For Loop

## How It Works

1. The program asks the user to enter a number.
2. It reads the input using the `Scanner` class.
3. A `for` loop iterates from **1 to 10**.
4. Each iteration multiplies the entered number by the loop counter.
5. The multiplication table is printed to the console.
