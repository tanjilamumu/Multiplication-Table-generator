## 📖 Overview

The **Multiplication Table Generator** is a beginner-friendly Java console application that prompts the user to enter a number and then prints its multiplication table from **1 to 10**.

This project demonstrates fundamental Java programming concepts including user input, loops, arithmetic operations, and formatted console output.

---

## ✨ Features

* ✅ Accepts user input using `Scanner`
* 🔢 Generates multiplication tables from **1 to 10**
* 🔄 Uses a `for` loop for repetition
* ⚡ Fast and lightweight console application
* 💻 Easy to understand for Java beginners
